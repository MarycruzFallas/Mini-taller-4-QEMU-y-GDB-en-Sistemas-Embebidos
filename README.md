# Mini-taller 4: QEMU y GDB en Sistemas Embebidos

Mini-taller desarrollado para el curso **Taller de Sistemas Embebidos**.

El objetivo de este repositorio es introducir el uso de **QEMU** y **GDB** para la depuración de sistemas embebidos, abordando conceptos como:

- Host y Target
- Cross-debugging
- Remote debugging
- QEMU y GDB
- gdbstub y gdbserver
- Breakpoints
- Ejecución paso a paso
- Inspección de variables
- Inspección de memoria
- Inspección de registros

## Estructura del repositorio

- `Presentacion/`: presentación utilizada durante el mini-taller.
- `Demo/`: archivos correspondientes a la demostración práctica.
- `Tutorial/`: tutorial guiado y archivos necesarios para la práctica.
- `Evaluacion/`: preguntas de evaluación del mini-taller.
- `Referencias/`: fuentes y documentación técnica utilizadas.

## Herramientas principales

- QEMU
- GNU GDB
- GNU Arm Embedded Toolchain
- GNU Make
