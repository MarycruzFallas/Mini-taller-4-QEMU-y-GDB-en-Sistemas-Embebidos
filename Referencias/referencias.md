# Referencias

Las siguientes fuentes fueron utilizadas como base para el desarrollo del mini-taller sobre QEMU y GDB en sistemas embebidos.

## Documentación oficial

### QEMU

- **QEMU Documentation — GDB usage**  
  Documentación oficial sobre el uso del `gdbstub`, las opciones `-s` y `-S`, conexión remota con GDB, breakpoints e inspección de registros y memoria.  
  https://www.qemu.org/docs/master/system/gdb.html

- **QEMU Documentation — System Emulation**  
  Documentación general sobre la emulación de sistemas completos mediante QEMU.  
  https://www.qemu.org/docs/master/system/index.html

- **QEMU Documentation — Arm System Emulator**  
  Documentación sobre la emulación de sistemas y máquinas basadas en arquitectura Arm.  
  https://www.qemu.org/docs/master/system/target-arm.html

---

### GNU GDB

- **GNU Project — Debugging with GDB**  
  Manual oficial de GNU GDB. Incluye comandos de ejecución, breakpoints, inspección de variables, memoria, registros y depuración de programas.  
  https://sourceware.org/gdb/current/onlinedocs/gdb/

- **GNU GDB — Remote Debugging**  
  Documentación oficial sobre depuración remota, conexión entre Host y Target y uso del protocolo remoto de GDB.  
  https://www.sourceware.org/gdb/current/onlinedocs/gdb.html/Remote-Debugging.html

---

### Arm

- **Arm — How to debug: CoreSight basics**  
  Material de Arm utilizado como referencia para comprender conceptos de depuración de sistemas basados en procesadores Arm y mecanismos de observación del sistema.  
  https://developer.arm.com/community/arm-community-blogs/b/architectures-and-processors-blog/posts/how-to-debug-coresight-basics-part-1

---

### AMD / Xilinx

- **AMD Adaptive Computing Wiki — Debugging Guest Applications with QEMU and GDB**  
  Referencia práctica sobre el uso conjunto de QEMU y GDB para depuración de aplicaciones ejecutadas sobre arquitecturas objetivo emuladas.  
  https://xilinx-wiki.atlassian.net/wiki/spaces/A/pages/821624963/Debugging+Guest+Applications+with+QEMU+and+GDB
